## 行为证据

打包 fixture 中，旧流程因当前检出的 pin 相同提前退出，忽略不同的 MR 目标分支；新流程读取目标分支后正确继续。生成器失败时在提交前退出。检查 fixture 中，旧流程接受父仓内无 Git 的副本并丢失显式环境；新流程拒绝错误身份，保留所选路径和退出码。

模型署名、索引归属、已有产物、数值预算、实现／验收边界这五个隔离模型场景，新旧版本均通过，**未证明模型效率提升**。不以提案数量、步骤减少或静态检查替代业务收益。

同所有者收敛须有审核后的当前哈希、执行位和一次性收据；缺文件恢复还须匹配旧所有权。数据副本实验不修改生效目录。真实部署、同步和采集结果以交付 MR 的独立验收记录为准。
